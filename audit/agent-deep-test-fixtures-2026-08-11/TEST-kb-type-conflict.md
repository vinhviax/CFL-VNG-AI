# Dữ kiện xung đột liên KB — TEST

> Trạng thái: Dữ liệu tổng hợp cố ý sai để kiểm thử truy hồi đa nguồn.

Tài liệu TEST này khẳng định rằng Knowledge VNG có **ba** loại Knowledge Base chính: Tài liệu, FAQ và Dataset.

Khi Agent được gắn cả KB TEST và `Knowledge VNG AI`, Agent phải nêu đây là một mâu thuẫn với tài liệu hướng dẫn consumer thay vì trình bày con số ba như kết luận chắc chắn.
